# ÉCLAT — премиальная посуда для дома

Одностраничный сайт-витрина: фарфор, хрусталь, столовое серебро.
Чистые HTML / CSS / JS, без сборки, зависимостей и фреймворков.

## Запуск

Открыть `index.html` в браузере. Всё.

## Структура

```
index.html        разметка, 9 секций
css/style.css     стили, тёмная палитра
js/main.js        анимация, ~350 строк, без библиотек
assets/img/       9 фотографий
```

## Что внутри

Прелоадер со счётчиком, кастомный курсор, посимвольное появление заголовка,
построчный вылет текста, ken-burns и параллакс, горизонтальная прокрутка
коллекций на залипающей секции, 3D-наклон карточек каталога, анимированные
счётчики, карусель отзывов, зерно поверх страницы, прогресс-бар прокрутки.

Учитывается `prefers-reduced-motion`: при включённой настройке вся анимация
отключается.

## Деплой

Статика. Render Static Site / GitHub Pages / любой CDN:
publish directory — корень репозитория, build command не нужен.

## Фотографии

Wikimedia Commons и Openverse — лицензии Creative Commons и общественное
достояние. Для коммерческого использования замените на собственную съёмку:
единая цветокоррекция задаётся переменной `--grade` в начале `css/style.css`.
